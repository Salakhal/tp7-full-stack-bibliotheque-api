# 📚 API de Gestion de Bibliothèque

## Description

API RESTful complète pour la gestion d'une bibliothèque. Cette application permet de gérer des utilisateurs, des auteurs, des livres et des emprunts avec un système d'authentification JWT et une gestion des rôles (utilisateur, bibliothécaire, admin).

## 🚀 Technologies utilisées

| Technologie | Version | Utilité |
|-------------|---------|---------|
| Node.js | 14+ | Runtime JavaScript |
| Express | 4.x | Framework web |
| TypeScript | 5.x | Typage statique |
| MongoDB | 6.x | Base de données |
| Mongoose | 7.x | ODM pour MongoDB |
| JWT | 9.x | Authentification |
| Joi | 17.x | Validation des données |
| Swagger | 5.x | Documentation API |
| Winston | 3.x | Logging |
| Helmet | 7.x | Sécurité HTTP |
| CORS | 2.x | Cross-origin资源共享 |

## 📋 Prérequis

- [Node.js](https://nodejs.org/) (version 14 ou supérieure)
- [MongoDB](https://www.mongodb.com/) (version 6 ou supérieure)
- [npm](https://www.npmjs.com/) (inclus avec Node.js)
